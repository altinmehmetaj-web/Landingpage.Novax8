# AVYRA — Landing V3

Versione V3 impostata come **VSL sales landing**, non come sito web tradizionale.

## Struttura
- Hero + VSL
- Step 02
- Opportunità
- Problema
- Metodo in 5 passaggi
- Manifesto
- Dimostrazione / scorecard
- Prove e testimonianze
- Cosa NON è
- Per chi è / non è
- Fondatore e team
- FAQ
- CTA finale

## Importante
Il percorso del CSS nell'`index.html` è:
`css/styles.css`

Il JavaScript è:
`js/config.js`
`js/script.js`

## Prima del lancio
Sostituire:
- `assets/videos/vsl.mp4`
- `assets/images/vsl-poster.jpg`
- video testimonianze
- foto fondatore/team
- nome AVYRA se viene scelto un altro brand
- CTA reale
- WhatsApp/email
- privacy/cookie
- testi e risultati con dati reali

I placeholder sono intenzionali: non vengono inventati risultati o testimonianze.

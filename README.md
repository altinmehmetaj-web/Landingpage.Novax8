# AVYRA — V1

Base pronta per GitHub Pages.

## Struttura

- `index.html` — pagina completa
- `css/styles.css` — design responsive
- `js/config.js` — telefono, WhatsApp, email e social
- `js/script.js` — menu, animazioni, contatori, link dinamici
- `assets/logo.svg` — logo provvisorio
- `assets/images/hero-poster.png` — poster temporaneo
- `assets/videos/` — inserire i video
- `assets/testimonials/` — inserire le testimonianze video

## Video

Sostituire questi file con video reali:

- `assets/videos/hero.mp4`
- `assets/videos/presentation.mp4`
- `assets/testimonials/testimonial-01.mp4`
- `assets/testimonials/testimonial-02.mp4`
- `assets/testimonials/testimonial-03.mp4`

## Contatti

Aprire `js/config.js` e sostituire:

- numero WhatsApp
- email
- Instagram
- TikTok
- YouTube
- Facebook

## Pubblicazione su GitHub

1. Crea un repository, per esempio `avyra`.
2. Carica tutti i file mantenendo la struttura delle cartelle.
3. Vai in Settings → Pages.
4. Seleziona Deploy from branch.
5. Seleziona `main` e `/root`.
6. Salva.

Il nome AVYRA è provvisorio: tutta la struttura è pensata per poterlo sostituire in un secondo momento con una semplice modifica.
